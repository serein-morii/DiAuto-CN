# DiAuto CN

在比亚迪车机上使用有线或无线 Android Auto。本分支基于上游 `v0.3.9`，已为简体中文补充应用界面翻译，并将桌面名称设为 **DiAuto CN**。

[上游项目](https://github.com/shihabal3amri/DiAuto) · [官方网站](https://shihabal3amri.github.io/DiAuto/) · [安装说明](docs/INSTALL.md)

请将应用安装在车机上，不要安装在手机上。连接时使用手机自带的 Android Auto，不需要额外的手机伴侣应用、转接盒、外接硬件、root 或改固件。这不是 Apple CarPlay，仍需要一部支持 Android Auto 的 Android 手机。

- 支持原生无线 Android Auto，并保留 USB 数据线连接。
- 在已验证固件上支持比亚迪 HUD 导航箭头、距离和道路名称。
- 支持车机热点、Wi-Fi Direct 以及简化后的主页和设置。
- 可将音乐改走车机蓝牙，避免与媒体焦点冲突。

## 兼容性

目前主要在 **比亚迪 DiLink 5.1 / Android 13** 上验证过无线和 USB 连接。其他车型和固件尚未确认。车机必须允许安装 APK。请在停车后安装和设置。
